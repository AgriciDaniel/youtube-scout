# Support

## Where to ask

- Bugs and feature requests: open an issue on this repository using the templates.
- Questions about using the skill inside Claude Code: see `SKILL.md` and the README FAQ first.
- Community discussion: AI Marketing Hub Pro at https://www.skool.com/ai-marketing-hub-pro

## Before opening an issue

1. Run `python -m pytest` in the repository; all tests should pass.
2. Note the exit code the script printed (see the exit code table in `SKILL.md`).
3. For `--hooks` problems, run `yt-dlp -U` first. Most caption and metadata failures are
   fixed by a yt-dlp update.
4. Never paste your API key or a key file into an issue. Redact anything after `key=` in URLs.

## Response time

This is a maintainer-run project. Expect a first response within a week.
